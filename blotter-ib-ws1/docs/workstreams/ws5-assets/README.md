## Purpose

This directory stores the limited set of visual references created outside Lovable for interface-heavy scenes that are difficult to communicate reliably through text alone.

Asset authority levels:

- `directional visual reference`: establishes approved direction but is not a literal pixel target;
- `formal exact implementation asset`: must be reproduced as specified and is not open to independent visual reinterpretation;
- `no external asset required`: the surface must be implemented from its ratified written specification and shared component system.

Every asset must be used with the ratified build specification for the exact surface and the canonical rules in WS3, WS4, and WS5.
