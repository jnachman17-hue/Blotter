# Hero spreadsheet reference v1

Status: Directional implementation reference



## Authoritative

- Google Sheets-native visual language and compact density.
- Current `IB Recruiting Tracker` data and column order.
- Student-maintained fields: Name, Title, Firm.
- Blotter-maintained fields: Status, Next move, Last contact, Days, Call.
- Three activity cues and their exact copy.
- Responsibility language: `YOU add the contacts` and `BLOTTER keeps them current`.
- Spreadsheet remains the dominant object.

## Directional only / defects to improve in Lovable
This is a directional visual guide to supply to Lovable to supplement text instructions. This is not perfect and should not be replicated pixel by pixel. There is room for improvement: 

- Cue-to-Blotter-to-sheet causality is not sufficiently clear.
- Cue-to-row or cue-to-field mapping is not sufficiently clear.
- The vertical Blotter engine is not a settled product diagram.
- Responsive composition must be designed in page context.
- We need to improve the right side. I'm unsatisfied with how the 3 action cues (Gmail, Calendar, Gmail) feed into the "blotter engine" feed into the spreadsheet. The actual action cues themselves are okay but the way this process is displayed is not clear and needs improvement. These are all notes to provide Lovable with and we must state the changes or improvement we want with text.
